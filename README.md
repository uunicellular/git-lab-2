# Лабораторна робота №2

**Тема:** Створення та налаштування репозиторію на GitHub, відстеження змін у проєкті.

**Мета роботи:** Закріпити навички роботи із системою контролю версій Git та платформою GitHub[cite: 1]. Навчитися створювати локальний і віддалений репозиторій, додавати файли, виконувати коміти, створювати гілки та синхронізувати зміни.
