Список тем для вивчення у цьому семестрі:

- Створення графічних інтерфейсів для вбудованих систем за допомогою LVGL.
- Поглиблене вивчення Python та розробка вебкомпонентів на React.
- Мережеві технології, маршрутизація та адміністрування Linux.
- Робота з API (як заплановано для експериментальної гілки).
